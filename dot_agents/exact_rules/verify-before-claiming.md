# Verify Before Claiming

A claim about work you did is only worth what a check can confirm. Make the
check.

## After an edit

Read the file back. Confirm the change is there.

## After a code change

Run the project test or check command. Do not report the change as done until
the command exits 0. If no check command exists, say so and name the reason.

## When you cite a path

Cite only paths and line numbers that a tool returned in this session. If you
have not opened the file, open it first. A citation you did not read is not
evidence.

## When you run a command

Show the command and its exit code.

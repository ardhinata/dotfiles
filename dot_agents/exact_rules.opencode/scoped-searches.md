# Scoped Searches — OpenCode

OpenCode tools and paths for the shared rule
`~/.agents/rules.personal.d/scoped-searches.md`.

## Dedicated tools

Use these before `grep -r`, `rg`, `find`, or `fd`:

| Job | Tool |
|---|---|
| Code and concept search | `aft_search` |
| File or directory structure | `aft_outline` |
| Read one symbol or section | `aft_zoom` |
| Find files by pattern | `glob` |
| Search file contents | `grep` |
| Read a file | `read` |

## Paths

| Looking for | Path |
|---|---|
| Global agent config, rules, skills | `~/.config/opencode/`, `~/.agents/` |

# ASD-STE100 Issue 9 — the 53 writing rules

Paraphrased rule catalog with the official numbers. The official wording is in the free
specification at `asd-ste100.org`. Request the PDF. ASD gives it at no cost.

Rule numbers changed between Issue 8 (2021) and Issue 9 (January 2025). The numbers below follow
Issue 9. Section 6 rule numbers are the least consistent between public sources — the limits are
well attested, the individual numbers are not. Make sure against the official PDF before you quote a
Section 6 number to a user.

## Section 1 — Words (1.1 to 1.14)

| Rule | Instruction |
| --- | --- |
| 1.1 | Use words that the dictionary approves, or technical nouns, or technical verbs. |
| 1.2 | Use an approved word only as the part of speech that the dictionary specifies. |
| 1.3 | Use an approved word only with its approved meaning. |
| 1.4 | Use only the approved forms of verbs and adjectives. |
| 1.5 | Use words that you can put in a technical noun category. |
| 1.6 | Use an unapproved word only when it is a technical noun, or part of one. |
| 1.7 | Do not use a technical noun as a verb. |
| 1.8 | Use technical nouns that your company, industry, or subject field approves. |
| 1.9 | When you must select a technical noun, select one that is short and easy to understand. |
| 1.10 | Do not use regional words, slang, or jargon as technical nouns. |
| 1.11 | Do not use different technical nouns for the same thing. |
| 1.12 | Use verbs that you can put in a technical verb category. |
| 1.13 | Do not use a technical verb as a noun. |
| 1.14 | Use American English spelling, unless an official directive tells you differently. |

## Section 2 — Multi-word nouns (2.1, 2.2)

| Rule | Instruction |
| --- | --- |
| 2.1 | Write a multi-word noun of not more than three nouns. |
| 2.2 | When a technical noun has more than three words, write it in full. Then give it a shorter name, or use hyphens. |

## Section 3 — Verbs (3.1 to 3.7)

| Rule | Instruction |
| --- | --- |
| 3.1 | Use only the verb forms that the dictionary gives. |
| 3.2 | Use only these forms: the infinitive, the imperative, the simple present, the simple past, the simple future, and the past participle as an adjective. |
| 3.3 | Use the past participle as an adjective. |
| 3.4 | Do not use auxiliary verbs to make a complex verb construction. |
| 3.5 | Use the "-ing" form of a verb only as a technical noun, or as a modifier in a technical noun. |
| 3.6 | Use the active voice. In descriptive writing you can use the passive voice only when the agent is unknown. |
| 3.7 | Use an approved verb for an action. Do not use a noun or another part of speech. |

## Section 4 — Sentences (4.1 to 4.5)

| Rule | Instruction |
| --- | --- |
| 4.1 | Write short and clear sentences. |
| 4.2 | Do not leave out words, and do not use contractions, to make a sentence shorter. |
| 4.3 | Use a vertical list for complex text. |
| 4.4 | Use connecting words and phrases to join sentences that hold related topics. |
| 4.5 | When applicable, put an article or a demonstrative adjective in front of a noun. |

## Section 5 — Procedures (5.1 to 5.5)

| Rule | Instruction |
| --- | --- |
| 5.1 | Write short sentences. The maximum is 20 words. |
| 5.2 | Write only one instruction in each sentence. Two instructions are permitted only when the actions occur at the same time. |
| 5.3 | Write an instruction in the imperative form. |
| 5.4 | When an instruction starts with a descriptive statement, put a comma between the statement and the command. |
| 5.5 | Write a note only to give information. A note must not give an instruction. |

## Section 6 — Descriptive writing

| Instruction | Note |
| --- | --- |
| Give information gradually. Give one new fact in each sentence. | |
| Use key words and phrases to give the text a logical structure. | |
| The maximum is 25 words in each sentence. | Well attested across sources |
| Group related information in a paragraph. | |
| Write one topic in each paragraph. | |
| The maximum is six sentences in each paragraph. | Well attested across sources |

Do not use the imperative form in descriptive text. A description explains. A procedure instructs.

## Section 7 — Safety instructions (7.1 to 7.3)

| Rule | Instruction |
| --- | --- |
| 7.1 | Use an applicable word to identify the level of risk. `WARNING` is for a risk to a person. `CAUTION` is for a risk to equipment. Other words are possible; agree them as a project rule. |
| 7.2 | Start a safety instruction with a clear and accurate command, or with a condition. |
| 7.3 | Give an explanation that shows the risk, or the possible result. |

Put a safety instruction in front of the step that it protects. Never put it after the step.

## Section 8 — Punctuation and word counts (8.1 to 8.7)

| Rule | Instruction |
| --- | --- |
| 8.1 | Use all standard English punctuation marks, but not the semicolon. |
| 8.2 | Use a hyphen to connect words that are directly related. |
| 8.3 | You can use parentheses. |
| 8.4 | In a vertical list, a colon has the same effect on the word count as a full stop. |
| 8.5 | Text in parentheses counts as one word in the sentence. |
| 8.6 | Count each of these as one word: a part number, a serial number, a date, a numeric value with its unit, and similar elements. |
| 8.7 | A hyphenated word counts as one word. |

Rules 8.4 to 8.7 change the arithmetic of rules 5.1 and the 25-word limit. Apply them before you
report a sentence as too long. The checker script applies them.

## Section 9 — Writing practices (9.1 to 9.4)

| Rule | Instruction |
| --- | --- |
| 9.1 | Use a different sentence construction when a word-for-word replacement is not sufficient. |
| 9.2 | Use each approved word correctly. |
| 9.3 | When you use two words together, do not make a phrasal verb. |
| 9.4 | When you select terminology or wording, always use a consistent style. |

## Grammar guidance topics (GR-1 to GR-8)

The specification adds guidance topics beside the numbered rules.

| Topic | Guidance |
| --- | --- |
| GR-1 | The conjunction `that`. Keep it. Do not leave it out after `make sure`. |
| GR-2 | The preposition `with`. Use it only with its approved meaning. |
| GR-3 | How to use pronouns. Repeat the noun when the pronoun is not clear. |
| GR-4 | The pronoun `this`. Put a noun after it: `this valve`, not `this`. |
| GR-5 | False friends. A word that looks the same in two languages can have two meanings. |
| GR-6 | Latin abbreviations. Do not use `e.g.`, `i.e.`, or `etc.` Write `for example`, `that is`, and a complete list. |
| GR-7 | Inclusive language. The dictionary holds no discriminatory terms. |
| GR-8 | The possessive form. Prefer `of` for a thing: `the cover of the pump`. |

## Two extra guidelines from The Global English Style Guide

Public checkers add these. They are not ASD-STE100 rules.

| Guideline | Instruction |
| --- | --- |
| Write positively | Do not use a double negative. Write `usual`, not `not unusual`. |
| Do not use `(s)` for a plural | Write `one or more valves`, not `valve(s)`. Rule 8.3 permits `(s)`, but it makes translation harder. |
| Do not use an ampersand | Write `and`. |
| Remove wordy phrases | Write `because`, not `due to the fact that`. |
